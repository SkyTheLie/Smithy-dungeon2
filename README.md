# Smithy Dungeon 2

Roguelite-RPG in Godot 4.7: Dungeon-Runs in Ego-Sicht (Feuerbälle, Items, Synergien, Bosse) und dazwischen der Laden eines gaunerhaften Händlers – Beute verkaufen, Glücksspiel-Ware würfeln, Ausrüstung und Relikte anlegen.

Nachfolger von [Dungeon Smithy](https://github.com/SkyTheLie/Smithy-dungeon); Grafik und Ton aus Smithy.

- Starten: Projekt in Godot 4.7 öffnen, F5.
- Tests: `bash assets/_reference/run_tests.sh`
- Überblick: `PROJEKT.md`, Ideen: `docs/IDEEN.md`, Plan: `docs/ROADMAP.md`
