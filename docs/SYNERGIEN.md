## Items ohne Synergie, die eine bräuchten

Reine Werte-Items (Schaden +, Herzen +, Tempo + …, 94 Stück) brauchen keine Synergie. Wichtig sind Items mit eigener Mechanik. Sortiert nach Nutzen:

### 1. Waffen ohne Kreuzung (passt zur neuen Idee „Waffen kreuzen“)

| Item | Vorschlag |
|---|---|
| Jagdbogen (Start Bogenschütze) | Bogen + Feuerstab = „Brandpfeile“ (Pfeile brennen, explodieren aufgeladen); Bogen + Schwert = „Klingenpfeil“ (aufgeladener Schwung wirft die Klinge) |
| Glutschwert, Kriegsaxt, Kriegerschwert | Schwert + Pulverhandschuh = „Sprenghieb“; Schwert + Feuerlanze = „Flammenklinge“ (Klinge wird zum kurzen Strahl); Axt + Bumerang-Haken = Wurfaxt |
| Wurfsterne, Klingenstern | + Suchender Funke = „Schwarm“; + Gegabelter Stab = Sternenfächer |
| Feuerlanze + Schwert, Pulverhandschuh + Schwert | heute gewinnt Strahl/Bombe und das Schwert verschwindet (gleiches Problem wie Axt beim Magier). Lösung: Kreuzungen wie Feuerhieb |

### 2. Zustände (Brennen, Gift, Frost, Furcht, Taumeln, Bluten)

Es gibt nur „Frost und Feuer“, und die gilt nur für Brandöl + Frostflechte.

- **Gruppen erweitern (schnell):** Frost und Feuer auch mit Feuerstab, Sonnenblume, Höllenstab, Nachtschatten (Brennen) und Eisstab, Frostkristall, Frostmähne, Sternenfessel, Spinnenseil (Kälte).
- Neue Synergien:
  - **Gift + Brennen** = „Giftrauch“: Giftzahn, Giftstab, Nachtschattensamen, Spinnenseil, Hexenkessel
  - **Furcht + Taumeln** = „Wahnsinn“: Schreckensbrief, Königsbrief, Taumelkraut, Schattenstab, Hexenkessel
  - **Bluten + Nahkampf** = „Blutrausch“: Wurfsterne, Klingenstern, Kriegsaxt
